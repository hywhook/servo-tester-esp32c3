Contexto del proyecto — Servo Tester ESP32-C3 Super Mini

Resumen completo y cronología de decisiones para retomar el trabajo más adelante. Todo lo creado en esta sesión, en un solo lugar.

ESP32-C3 Super MiniPlatformIO / ArduinoSesión 30-ago-2026Repo: servo-tester-esp32c3

1. Objetivo

Construir un probador de servos profesional para el ESP32-C3 Super Mini, controlado con un encoder rotativo HW-040 (no potenciómetro) y con un OLED SSD1306 I2C que muestra el ángulo y los microsegundos. Entregado en 3 niveles crecientes, cada uno un proyecto PlatformIO autónomo, con manuales HTML en modo oscuro y diagramas de circuito SVG a color.

2. Cómo llegamos aquí (cronología)

  • Inicio: prototipo con potenciómetro leyendo ADC (GPIO4). Compiló y se flasheó al ESP para probar detección/toolchain.
  • Cambio de paradigma: el usuario consultó por el HW-040. Decidimos usarlo: el pot es absoluto (ADC) pero ruidoso en C3; el encoder es incremental (contador en software), sin ADC y con botón para el menú. Mejor para un tester.
  • Alcance: el usuario pidió los 3 niveles por separado + manuales completos + subir a GitHub.
  • Nivel 1: menú + modos Manual/Sweep/Center + lectura en µs + límites persistidos (Preferences).
  • Nivel 2: + analizador V/I (divisor de tensión + INA219 en serie) + alarma.
  • Nivel 3: + 4 canales + BLE (NimBLE) + gráfico de respuesta.
  • Manuales: primero en Markdown; luego el usuario pidió HTML con colores y todo el detalle.
  • Ajuste final: usuario pidió modo oscuro en todas las páginas y diagramas de circuito SVG a color (por señal, con leyenda).
  • Flash: se cargó el Nivel 1 en la ESP conectada (/dev/ttyACM0). Sin OLED/encoder/servo cableados aún, el firmware queda esperando el OLED en setup().

⚠️ Gotcha USB-CDC (crítico, ya nos quemó una compilación): el core framework-arduinoespressif32 7.0.1 no incluye usb_serial.h para C3. Por eso ningún nivel usa ARDUINO_USB_CDC_ON_BOOT=1: al ponerlo, Serial queda sin definir y no compila. Serial cae a UART0 (GPIO1/3), que el Super Mini no cablea al USB → el debug se hace por el OLED, no por el monitor serie USB. platformio.ini lleva board_build.flash_mode = dio.

6. Estado actual y cómo retomar

Estado

  • Los 3 niveles compilan (verificado con pio run).
  • Nivel 1 está flasheado en la ESP conectada (/dev/ttyACM0). Falta cablear OLED + encoder + servo para verlo vivo (sin OLED se queda en setup() esperando el display).
  • Manuales HTML en dark mode con diagramas SVG a color, subidos.

Para retomar

  1. Clonar: git clone https://github.com/hywhook/servo-tester-esp32c3
  2. Leer index.html y el manual.html del nivel deseado.
  3. Para probar en hardware: cablear según el diagrama SVG del manual, luego cd nivelN && pio run -t upload.
  4. Si se quiere flashear otro nivel (p. ej. L3 con BLE), misma carpeta y comando; el flash anterior se sobrescribe.
