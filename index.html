Servo Tester ESP32-C3 Super Mini

Probador de servos profesional en 3 niveles crecientes para el ESP32-C3 Super Mini. Cada nivel es un proyecto PlatformIO autónomo con su manual HTML completo.

ESP32-C3PlatformIOArduinoOLED SSD1306Encoder HW-040INA219 (L2/L3)BLE (L3)
Nivel 1

Menú + µs

Menú navegable, modos Manual / Sweep / Center, lectura en microsegundos y límites de recorrido persistidos en Preferences.

Ver manual →
Nivel 2

Analizador V/I

Nivel 1 + medición de tensión (divisor) y corriente (INA219 en serie) + alarma por sobrecorriente/bajo voltaje.

Ver manual →
Nivel 3

Premium

Nivel 2 + 4 canales, BLE (NimBLE, control desde el celu) y gráfico de respuesta en el OLED.

Ver manual →
⚠️ Gotcha USB-CDC: el core framework-arduinoespressif32 7.0.1 no incluye usb_serial.h para C3, por eso ningún nivel usa ARDUINO_USB_CDC_ON_BOOT. El Serial cae a UART0 (GPIO1/3), que el Super Mini no cablea al USB: el debug se hace por el OLED.

Inicio rápido

git clone https://github.com/hywhook/servo-tester-esp32c3 cd servo-tester-esp32c3/nivel1 # o nivel2 / nivel3 pio run -t upload # sube por el USB nativo

Cada carpeta tiene su platformio.ini, src/main.cpp y manual.html. Los manuales en Markdown (README.md) quedan como fuente; la versión definitiva es el HTML.
